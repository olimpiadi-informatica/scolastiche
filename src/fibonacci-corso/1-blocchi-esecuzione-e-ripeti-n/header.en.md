# Block Programming Course

## Lesson 1 - Execution Blocks and Repeat N

Welcome to the block programming course for preparation for the Fibonacci Games!

This is your first lesson, where we will introduce:

- how block programming problems work;
- the simplest blocks of the “execution” type;
- the “repeat N times” block.

## Points and lesson structure

The lessons in this course contain block-programming problems to be solved in no more than _4 days_. As soon as you finish, you can click “Finish” to immediately see a summary of your score and the explained solutions to every problem. If you do not do so, the lesson will finish automatically after 4 days. You can restart the lesson as many times as you wish by clicking the “Restart” button (the curved arrow pointing backward).

The problems require you to write a **single** block program that is evaluated **simultaneously** at several levels.
Be careful: you cannot write a different program for each level; you must write only one!
For each level of each problem that you solve correctly, you will earn _5 points_.

At the end of the lesson, we recommend that you **read all the explained solutions**, including those for problems you solved correctly: you may discover other ways to solve the same problems and find hints that will help you with similar problems in the future!
